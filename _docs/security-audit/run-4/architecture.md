## Product and trust model
A private account-based weekly reflection/journal web app, comparable to private notes/journaling products (Day One/Joplin-style account separation), not a CMS. Each user owns reviews, reports, insights and commitments, and may edit/delete their own data. Other users knowing resource IDs must not gain access. Trusted operators control signing/database/provider/exporter configuration and deployment. No public sharing or teams/role hierarchy. Django admin has its own staff/session/CSRF boundary.
